# Develop-unit-tests-using-GitHub-Copilot

## Lab environment

Before starting the lab, make sure your environment includes:

- Git 2.48 or later (`git --version`).
- The .NET SDK 9.0 or later (`dotnet --list-sdks`).
- Visual Studio Code 1.116 or later (`code --version`).
- The C# Dev Kit extension (`ms-dotnettools.csdevkit`). Install it with `code --install-extension ms-dotnettools.csdevkit`.
- A GitHub account with GitHub Copilot enabled. Sign in to GitHub Copilot in VS Code with that account.
